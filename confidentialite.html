Mesure d’audience Cloudflare

Si vous choisissez « Autoriser la mesure », le script Cloudflare Web Analytics recueille des indicateurs de fréquentation et de performance à partir des informations de navigation exposées par le navigateur. Le script n’est pas chargé en cas de refus ou en l’absence de choix.

Cloudflare indique que Web Analytics mesure des métriques de performance et ne collecte ni n’utilise les données personnelles des visiteurs. Cette affirmation décrit le service du fournisseur ; le site ne revendique pas pour autant une exemption de consentement reconnue par la CNIL.

Base légale : le consentement préalable donné dans le panneau de choix. Le refus n’empêche pas de consulter le portfolio. Vous pouvez modifier votre choix ou retirer votre accord depuis le lien de préférences.

Votre choix est conservé dans le stockage local de ce navigateur. Vous pouvez le modifier à tout moment depuis les préférences en bas de la page d’accueil.

Destinataire : Cloudflare, qui reçoit les requêtes du beacon lorsque vous autorisez la mesure.

Conservation annoncée par Cloudflare : les données beacon non échantillonnées sont conservées 7 jours, puis agrégées à environ 10 % du volume initial ; les données sont consultables dans Web Analytics sur une période de 6 mois. Cloudflare indique ne pas journaliser les paramètres de requête (query strings).

Pour les modalités détaillées et les transferts éventuels, consultez la politique de confidentialité Cloudflare et sa documentation de protection des données.

Hébergement et contact

Le site est hébergé par GitHub Pages. GitHub reçoit les requêtes nécessaires à l’affichage du site et les traite selon sa politique de confidentialité. Le lien de contact ouvre votre application de messagerie : le site ne reçoit pas le message que vous choisissez de lui envoyer.
