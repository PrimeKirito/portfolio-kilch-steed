# Portfolio de Kilch Steed EYEGHE

Portfolio professionnel en français, à l'esthétique éditoriale, conçu avec HTML, CSS et JavaScript natifs.

## Contenu
- `index.html` : page d'accueil, profil issu du CV, sélection de projets, parcours professionnel, compétences et contact.
- `styles.css` : système visuel responsive ivoire, noir et bleu électrique.
- `script.js` : filtres de projets, navigation mobile et fiches projets.
- `assets/` : illustrations SVG locales et favicon.

## Publication avec GitHub Pages
1. Ouvrir **Settings → Pages** dans ce dépôt.
2. Dans **Build and deployment**, choisir **Deploy from a branch**.
3. Sélectionner la branche `main` et le dossier `/(root)`, puis enregistrer.
4. Attendre la fin du déploiement et ouvrir l'URL affichée dans **Settings → Pages**.

URL prévue pour ce dépôt : https://primekirito.github.io/portfolio-kilch-steed/

## Profil et parcours
Le contenu du profil a été enrichi à partir du CV fourni : Master Humanités numériques (parcours NET), licence en anthropologie, expériences à l’agence 893°, chez Coopanam et chez Clarissime Services, compétences, outils et langues. Les informations doivent être relues par le propriétaire avant la diffusion publique.

## Personnalisation avant partage
- Vérifier l'adresse professionnelle affichée dans `index.html`.
- Remplacer les illustrations dans `assets/` par des visuels dont la diffusion est autorisée.
- Mettre à jour les fiches projet dans `script.js` avec le contexte, la contribution réelle, les livrables et les résultats vérifiables.
- Ne pas publier d'informations confidentielles appartenant à un client ou à un tiers.

## Confidentialité et maintenance
Le site ne comporte ni formulaire de collecte, ni compte visiteur, ni outil analytique, ni API d'IA. Les styles et scripts sont hébergés dans ce dépôt. Il n'utilise pas de polices ni de scripts provenant de services tiers. L'hébergement GitHub peut néanmoins traiter des données techniques de connexion conformément à ses propres politiques.

## Technologie
HTML sémantique, CSS responsive et JavaScript natif. Aucun gestionnaire de dépendances ou processus de compilation n'est nécessaire.
